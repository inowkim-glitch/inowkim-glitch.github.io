# 진일 통합관리 설치형 Windows 프로그램

## 목표
- 서울·화성에 설치되는 Windows EXE에서 같은 웹 서비스와 Supabase 데이터 원본을 사용.
- EXE 프로그램 창은 주소 표시줄 없이 실행.
- GitHub Pages 주소를 프로그램 내부에서 열므로 인터넷 연결 필요.
- 현재는 기존 연결 테스트 사이트를 표시. V72 통합 및 실제 데이터 연동이 완료되면 동일 URL에 최종 프로그램 배포.

## 로컬 Windows 빌드
1. Node.js LTS 설치.
2. 이 폴더에서 npm install
3. npm start 로 프로그램 창 테스트.
4. npm run build 로 NSIS 설치 프로그램 제작.

## 중요
- 현재 EXE 바이너리는 아직 빌드·실행 검증되지 않았음.
- electron-builder 설치파일은 코드 서명이 없어 Windows Smart App Control/SmartScreen 경고가 발생할 수 있음.
- 주소창을 숨겨도 웹의 HTML/JS 코드를 비공개로 만들 수는 없음.
- 로그인 세션 및 동기화 안전성은 별도 실기기 테스트 필요.
- 기존 서비스(main)나 데이터베이스는 이 소스 추가만으로 변경되지 않음.
