# V81 발주 수정·취소 작업 잠금 (운영 미적용)
- 기존 취소/완료 취소 버튼의 이름, 클래스, 위치 및 기존 CSS 변경 없음. 수정 버튼은 이전 승인 범위.
- 발송 발주: 총무부 staff / 총무부 super_admin만 잠금·수정·취소. 기존 admin 조회 권한을 확대하지 않음.
- 90초 임대, 20초 갱신; 취소/저장/닫기에서 해제. 연결 끊김 때 자동 만료. 동일 발주만 잠금; 열려 있는 현장 상세는 2초 간격으로 확인.
- 완료·취소된 발주 수정·취소는 기존 보류 유지. 발주 취소는 삭제 없이 상태 및 이력 보존. 별도 취소 사유 입력은 추가하지 않음.
- DB 변경은 combined activation plan 한 파일만 사용. 실제 PostgreSQL/RLS/두 기기 검증 전 운영 반영 금지. 로컬 브라우저 테스트 미완료.
- 기존 알림 테이블에 수정/취소 안내 갱신; 기존 실시간 알림 모듈의 같은 알림 ID 재표시는 별도 검증 필요.
