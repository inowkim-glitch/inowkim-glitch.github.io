진일 V72 개발용 원클릭 실행 안내
==================================

1. GitHub 개발 브랜치의 ZIP 파일을 다운로드합니다.
2. ZIP 파일 전체를 C:\진일_통합관리 폴더로 압축 해제합니다.
   * 압축을 풀면 GitHub 폴더가 한 단계 더 생겨도 괜찮습니다.
   * 이 진일_실행.cmd 파일과 tools, 진일_통합관리 폴더는 같은 상위 폴더에 있어야 합니다.
3. 진일_실행.cmd 파일을 더블클릭합니다.
4. CMD 창에 개발용 Python 서버가 실행되며 웹 브라우저에서 V72 화면이 자동으로 열립니다.
5. CMD 창은 닫지 마세요. 닫으면 개발용 서버도 종료됩니다.

기본 포트: 8004
8004 포트가 이미 사용 중이면 자동으로 빈 포트를 선택합니다.
웹 주소가 바뀌면 CMD 창에 정확한 새 주소가 표시됩니다.

참고:
- ZIP을 압축 해제하는 행위만으로 프로그램이 자동 실행되지는 않습니다.
- 이 실행기는 개발용 로컬 서버이며 127.0.0.1에서만 접속됩니다.
- 개발 PC에는 Python 3가 필요합니다.
- 다른 회원 PC/태블릿/휴대폰은 정식 웹 배포 후 Python이 필요 없습니다.
- 기존 업무 데이터나 Supabase 운영 데이터는 수정하지 않습니다.
