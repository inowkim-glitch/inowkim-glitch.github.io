진일 V79 개발용 원클릭 실행 안내
==================================

1. GitHub 개발 브랜치의 ZIP 파일을 다운로드합니다.
2. ZIP 파일 전체를 C:\진일_통합관리 폴더로 압축 해제합니다.
   * 압축을 풀면 GitHub 폴더가 한 단계 더 생겨도 괜찮습니다.
   * 이 진일_실행.cmd 파일과 tools, 진일_통합관리 폴더는 같은 상위 폴더에 있어야 합니다.
3. 진일_실행.cmd 파일을 더블클릭합니다.
4. CMD 창에 개발용 Python 서버가 실행되며 웹 브라우저에서 V79 관리자 트리형 화면이 포함된 메인 페이지가 자동으로 열립니다.
5. CMD 창은 닫지 마세요. 닫으면 개발용 서버도 종료됩니다.

기본 포트: 8004
8004 포트가 이미 사용 중이면 자동으로 빈 포트를 선택합니다.
웹 주소가 바뀌면 CMD 창에 정확한 새 주소가 표시됩니다.

참고:
- ZIP을 압축 해제하는 행위만으로 프로그램이 자동 실행되지는 않습니다.
- 이 실행기는 개발용 로컬 서버이며 127.0.0.1에서만 접속됩니다.
- 개발 PC에는 Python 3가 필요합니다.
- 다른 회원 PC/태블릿/휴대폰은 정식 웹 배포 후 Python이 필요 없습니다.
- 기존 업무 데이터나 Supabase 운영 데이터는 수정하지 않습니다.

V79 업데이트 안내:
- 예전 ZIP의 파일만 실행하면 V72가 나타납니다. GitHub 개발 브랜치의 최신 ZIP 전체를 다시 압축 해제해야 합니다.
- 시작 대상: 진일_통합관리/11_1_v79_진일_통합_실시간_관리_시스템_재작업.html
- 원본 V72 파일은 보존합니다.
- GitHub Pages 운영 배포는 하지 않습니다.

V79 발주 알림 개발 안내:
- 로그인 후 좌측 아래 '발주 알림' 버튼에서 중앙 안내·우측 아래 알림·소리 설정을 변경합니다.
- Supabase 진일 발주 알림 테이블에서 본인에게 발송된 신규 항목만 수신합니다.
- 기존 발주 INSERT 트리거·RLS·Realtime는 재사용합니다.
- 휴대폰 OS 푸시 구독은 별도 기기 설정이 필요하며, OS 자동 발주 발송 경로는 아직 완료되지 않았습니다.
- 실제 회원 로그인·모바일 기기 테스트 및 운영 배포는 미실시입니다.

V79 안내: 총무과 발주 작성·저장·부서별 전송 및 부서 대기·확인·완료 메뉴에 기존 Supabase 실연동 어댑터를 연결했습니다. 권한·서버 데이터는 기존 Supabase 구조와 정책을 사용합니다. PC/모바일 기기 최종 체험 시험은 일괄 검증 목록에 따릅니다.
