# 진일 통합 5단계 실제 데이터베이스 시험 기록 (2026-11-23)

## 작업 기준
V72 HTML 원본, 292쪽 기술기록, 12단계/38개 파일 트리 재확인. 기존 메인 배포 화면을 삭제하거나 교체하지 않음.

## 실제 적용 완료
- Supabase 기존 7개 테이블 보존.
- 신규 public.jinil_orders / public.jinil_dispatches 확인.
- 수신 부서별 송부 기록과 상태(대기/확인/완료).
- 상태 건너뛰기 차단 트리거 적용.
- 총무부/생산부 프로필의 부서명 별칭 규칙 반영.
- GitHub 통합 브랜치의 Supabase 주문 어댑터를 실제 스키마에 맞춰 수정.
- 실제 사이트 main에 독립 시험 페이지 integration-test/order-flow.html 추가. 기존 index.html 교체 없음.

## 검증
- 트랜잭션 내 시험 발주 삽입 및 부서 송부 성공.
- '대기 → 완료' 순서 건너뛰기 거부 확인.
- '대기 → 확인 → 완료' 정상 변경 확인.
- 서로 다른 Supabase 계정의 권한 문맥으로 총무부 송부/생산부 확인 및 완료 성공.
- 매 시험은 ROLLBACK 실행 후 발주 0건/송부 0건 유지 확인.

## 아직 확인되지 않은 부분
- 실제 서울·화성 두 기기와 브라우저 로그인에 의한 E2E 시험.
- V72 전체 업무 UI 버튼과 Supabase 원본 DB의 26개 독립 HTML 연결.
- 가공 소재 수신/입고, 재고 실시간 동기화, 슈퍼바이저 관리, 모바일 푸시.
- Windows EXE 설치파일 실물 빌드 및 인증서.
- Pages 신규 시험 페이지의 외부 접근과 Realtime replication은 실제 클라이언트 시험 필요.

**주의:** 이 단계의 시험은 DB 권한 역할을 전환해 수행한 서버 측 검증이며, 실제 사용자 PC/태블릿에서의 실기기 시험을 통과했다고 표시하지 않습니다.
