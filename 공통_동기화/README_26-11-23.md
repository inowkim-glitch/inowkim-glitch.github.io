# 동기화 연결 원칙

업무 버튼 클릭은 즉시 동기화 시도를 요청한다. 성공 메시지는 Supabase 요청 및 확인이 모두 끝난 후에만 표시한다.

- 한국시간 06:00부터 19:00까지 매시 정각
- 22:00, 다음날 01:00, 04:00
- 중복 시간 요청 합치기
- 오프라인 입력은 로컬 안전 큐에 보관, 온라인 복귀 후 충돌 확인
- 저장/수정/삭제 버튼은 실제 변경사항을 보낸다. 조회 버튼은 서버의 최신 상태를 가져온다.
- 작업 실패 시 성공 메시지를 표시하지 않는다.
- 서버 실시간 변경 통지는 일정 기반 동기화와 별개로 설계한다.

이 폴더의 스케줄러만으로는 실시간 DB 연결이 완성되지 않는다. V72 OrderRepository와 업체/재고 저장 경로를 서버 송수신으로 교체하고 RLS를 테스트해야 한다.
